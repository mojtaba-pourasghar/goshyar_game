# استودیوی صداگذاری گوش‌یار

ابزارِ محلی برای ساختِ **صدای موقتِ** گوینده با سرویسِ TTS «آواشو»، تا وقتی گوینده‌ی واقعی
جمله‌ها را ضبط کند. روی سیستمِ خودت اجرا می‌شود، توکن را خودت در صفحه وارد می‌کنی و
**هیچ‌چیز خودکار جایی آپلود یا پوش نمی‌شود.**

## به کجا وصل است

| چه | کجا |
|---|---|
| متنِ جمله‌ها | `assets/content/voice_lines.json` (همان فایلی که برنامه می‌خواند؛ ۲۲۰ جمله) |
| نامِ هر فایل | همان فیلدِ `file` در JSON، مثلاً `who_01_q.mp3` |
| خروجی | `assets/audio/voice/` — برنامه بی‌هیچ تنظیمِ دیگری پخششان می‌کند |
| قالبِ خروجی | MP3 مونو ۹۶kbps، بلندی −۱۶ LUFS، سکوتِ کوتاهِ اول و آخر (با ffmpeg)؛ دقیقاً مثلِ ضبط‌های انسانی |
| فهرستِ صداهای ماشینی | `docs/voice/tts_generated.json` (در گیت) |
| تلفظِ ویژه | فیلدِ اختیاریِ `spoken` در همان JSON؛ برنامه آن را نمی‌خواند، فقط استودیو |
| بسته‌ی CDN | دکمه‌ی «ساختِ بسته‌ی voice-fa» ← `cloudflare/scripts/build_packs.py` |
| صداهای آزمایشی | `tools/voice-studio/samples/` (بیرونِ برنامه، در گیت نیست) |

## صدای ماشینی و ضبطِ انسانی کنارِ هم

- هر کلیپی که استودیو می‌سازد در `docs/voice/tts_generated.json` ثبت می‌شود و در فهرست با برچسبِ «ماشینی» دیده می‌شود.
- استودیو **هرگز** فایلی را که در این فهرست نیست بازنویسی یا پاک نمی‌کند — یعنی ضبطِ گوینده‌ی واقعی همیشه امن است.
- وقتی ضبط‌ها رسید: `tools/voice/import_recordings.sh <پوشه‌ی فایل‌های استودیو>`. فایل‌ها با همان نام جای صدای ماشینی را می‌گیرند و از فهرستِ ماشینی برداشته می‌شوند.
- `docs/voice/recording_list.csv` برای هر جمله می‌گوید `yes` (ضبط‌شده)، `tts` (موقت) یا `no` (بی‌فایل).

## اجرا

نیاز: Node 18 یا بالاتر، Python 3، و ffmpeg روی PATH.

```bash
cd tools/voice-studio
npm install
npm start
```

بعد مرورگر را باز کن روی <http://127.0.0.1:5174>.

## بارِ اول

۱. **توکن** آواشو را در کادرِ «توکنِ آواشو» بچسبان و «ذخیره‌ی تنظیمات» را بزن
   (در `voice-studio.config.json` کنارِ همین پوشه ذخیره می‌شود و در گیت نیست).
۲. «تستِ صدا با یک جمله» — برای شنیدنِ گوینده و سرعت، پیش از ساختِ همه.
۳. در تبِ «تستِ وب‌سرویس»، «نمونه‌ی سرعت‌ها» گوینده‌ها و سرعت‌ها را کنارِ هم می‌سازد تا با گوش انتخاب کنی.
۴. «ساختِ همه‌ی باقی‌مانده‌ها» یا ساختِ دسته‌ای (صفحه‌ها، هر بازی، هر مرحله، مدال‌ها، نام صداها…).

اگر واژه‌ای بد خوانده شد، «متن» را بزن و تلفظ را با اعراب بنویس؛ در `spoken` همان جمله ذخیره
می‌شود و متنِ نمایشیِ برنامه دست نمی‌خورد.

## پس از ساخت

```bash
cd ../..
python3 tools/voice/make_recording_script.py     # وضعیتِ هر جمله در recording_list.csv
flutter run                                      # صدای گوش‌یار حالا شنیده می‌شود
```

برای انتشار روی CDN: دکمه‌ی «ساختِ بسته‌ی voice-fa»، بعد `cloudflare/scripts/upload.sh v1`
(راهنما: `cloudflare/README.md`). آپلود با FTP هم مثل قبل هست ولی اختیاری است.

## آزمایش بدون توکن

`AVASHO_HOST` آدرسِ سرویس را عوض می‌کند تا بشود با یک سرورِ ساختگیِ محلی آزمایش کرد:

```bash
AVASHO_HOST=http://127.0.0.1:9911 npm run server
```
