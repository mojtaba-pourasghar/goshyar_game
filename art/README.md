# گرافیک گوش‌یار

هدف: همان استایل اینفوگرافیک‌های مرجع — کاراکترهای سه‌بعدی گرد و براق،
رنگ‌های روشن و اشباع، پس‌زمینه سفید تمیز.

## فایل‌ها
- `art_manifest.json` — فهرست کامل **۶۹ تصویر** مورد نیاز بازی، هرکدام با
  نام مقصدش در `res/drawable/` و prompt دقیق و یکدستش.
- `previews/` — پیش‌نمایش ۲۰۰×۲۰۰ تصویرهایی که تا الان با Canva ساخته شده‌اند.
  **اینها فقط برای مرجع‌اند و نباید در برنامه استفاده شوند.**

## وضعیت
۸ تصویر ساخته شده (۴ ژست ماسکوت + شیر، گاو، گربه، سگ). شناسه Canva هرکدام
در `art_manifest.json` زیر `canvaMediaId` ثبت است. ۶۱ تصویر باقی مانده.

## افزودن تصویرهای نهایی
۱. فایل PNG با کیفیت کامل (۵۱۲×۵۱۲ برای کارت‌ها، ۱۰۸۰×۱۶۲۰ برای پس‌زمینه‌ها)
   را از Canva دانلود کنید.
۲. در `art/incoming/` با همان نام `target` بگذارید، مثلاً `img_lion.png`.
۳. اجرا کنید:

```bash
python3 tools/install_art.py
```

اسکریپت فایل‌ها را به `app/src/main/res/drawable/` منتقل می‌کند و گزارش می‌دهد
کدام نام‌ها هنوز کم است. نام‌ها دقیقاً همان چیزی است که `levels.json` انتظار دارد،
پس تا تصویری اضافه نشده، برنامه به‌جایش `mascot_thinking` را نشان می‌دهد و کرش نمی‌کند.
