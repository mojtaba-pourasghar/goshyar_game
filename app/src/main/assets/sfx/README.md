# فایل‌های صوتی بازی

هر صدا در `assets/levels.json` با نام فایلش معرفی شده است، مثلاً:

```json
{ "id": "lion", "title": "شیر", "audio": "sfx/animals_lion.mp3" }
```

فایل‌های mp3 را با همان نام در همین پوشه بگذارید.

تا وقتی فایلی موجود نباشد، `AudioManagerHelper` به‌جایش یک تُن ساده
می‌نوازد تا بازی قابل اجرا بماند — پس برنامه بدون این فایل‌ها هم اجرا می‌شود،
ولی برای انتشار واقعی باید همه‌شان اضافه شوند.

وضعیت موجود بودن فایل‌ها از داخل خود برنامه در صفحه «حالت آفلاین» دیده می‌شود.

## صداهای رابط کاربری (اختیاری)
- `sfx/ui_success.mp3` — پاسخ درست
- `sfx/ui_fail.mp3` — پاسخ غلط
- `sfx/ui_tap.mp3` — لمس دکمه
