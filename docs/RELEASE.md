# ساخت نسخه‌ی release و انتشار در کافه‌بازار

## debug و release چه فرقی دارند

| | debug (دکمه‌ی Run در Android Studio) | release (برای بازار) |
|---|---|---|
| مرحله‌ها | **همه باز**، بی‌ترتیب و بی‌خرید | در هر بازی **فقط مرحله‌ی ۱** رایگان؛ بقیه با «نسخه‌ی کامل» |
| پرداخت | لازم نیست | کافه‌بازار (Poolakey) |
| امضا | کلید debug | کلید release شما |

## ۱. یک بار: ساخت کلید امضا (keystore)

**با Android Studio:**
1. پوشه‌ی `android` پروژه را در Android Studio باز کنید (File ← Open ← `goshyar_game/android`).
2. منوی **Build ← Generate Signed App Bundle / APK** ← **APK** ← Next.
3. زیر Key store path، **Create new…** را بزنید:
   - مسیر: مثلاً `C:\MyData\Keys\goshyar-release.jks` (**بیرون از پروژه**)
   - رمز keystore و رمز کلید را بگذارید. Alias: `goshyar`. Validity: `25`. نام و شهر را پر کنید.
4. OK بزنید. **کلید ساخته شد؛ پنجره را ببندید** (ادامه‌ی ساخت را با Flutter انجام می‌دهیم).

**یا با خط فرمان:**
```powershell
keytool -genkey -v -keystore C:\MyData\Keys\goshyar-release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias goshyar
```

⚠️ از فایل `.jks` و رمزهایش **پشتیبان** بگیرید. اگر گم شود، دیگر نمی‌توانید نسخه‌ی تازه روی همین برنامه در بازار منتشر کنید.

## ۲. یک بار: `android/key.properties`
`android/key.properties.example` را کپی کنید به `android/key.properties` و پر کنید:
```properties
storePassword=رمز keystore
keyPassword=رمز کلید
keyAlias=goshyar
storeFile=C:/MyData/Keys/goshyar-release.jks
```
(در مسیر ویندوز از `/` استفاده کنید.) این فایل در گیت نیست.

## ۳. یک بار: پنل کافه‌بازار و `android/services.properties`
1. در [پنل توسعه‌دهندگان کافه‌بازار](https://pishkhan.cafebazaar.ir) برنامه‌ی `com.goshyar.app` را بسازید.
2. **پرداخت درون‌برنامه‌ای** ← محصول تازه:
   - نوع: **مصرف‌نشدنی** (یک بار خرید، برای همیشه)
   - شناسه (SKU): **`goshyar_full`**
   - قیمت: **۱۸۰٬۰۰۰ تومان**
3. از همان بخش **کلید RSA** را کپی کنید.
4. `android/services.properties.example` را کپی کنید به `android/services.properties`:
   ```properties
   bazaar.rsa=کلید RSA از پنل بازار
   pushe.token=توکن SDK از کنسول پوشه (اگر اعلان می‌خواهید)
   ```
قیمتی که در برنامه دیده می‌شود از خود بازار خوانده می‌شود؛ اگر نشد، «۱۸۰٬۰۰۰ تومان» نشان داده می‌شود.

## ۴. هر بار: ساخت فایل release
در ترمینال Android Studio (پایین صفحه، تب **Terminal**) در پوشه‌ی پروژه:
```powershell
flutter build apk --release
```
خروجی: `build\app\outputs\flutter-apk\app-release.apk` ← همین را در پنل بازار بارگذاری کنید.
(برای بسته‌ی کوچک‌تر: `flutter build appbundle --release` ← `build\app\outputs\bundle\release\app-release.aab`)

پیش از هر انتشار، `version` را در `pubspec.yaml` بالا ببرید (مثلاً `2.0.1+3`؛ عدد بعد از `+` باید هر بار بیشتر شود).

**نصب release روی گوشی خودتان برای آزمایش:** `flutter run --release` (گوشی با کابل وصل).
خرید فقط وقتی کار می‌کند که کافه‌بازار روی گوشی نصب و وارد حساب شده باشد. برای خرید آزمایشی، شماره‌ی حساب
بازار خود را در پنل به‌عنوان «آزمایش‌کننده» ثبت کنید.

## خبرهای امضاشده (بدون سرویس بیرونی)
- **یک بار:** استودیو (`tools/voice-studio`) ← تب «خبرها» ← «ساخت کلید امضا». فایل
  `assets/notices/notice-key.pub` را **کامیت کنید**. نیمه‌ی خصوصی فقط در
  `tools/voice-studio/voice-studio.config.json` است (در گیت نیست). از آن پشتیبان امن بگیرید؛
  گمش کنید، تا نسخه‌ی تازه‌ای با کلید تازه منتشر نشود خبری نمی‌شود فرستاد.
- **ساخت:** مثل هوهو ریاضی، خبرها از هاست خود سازنده خوانده می‌شوند:
  `https://mp-apdl.ir/goshyar/notices.json` (پیش‌فرض؛ با `--dart-define=GOSHYAR_NOTICES_BASE=…` عوض
  می‌شود). به CDN نیازی نیست. بی کلید، زنگوله و گزینه‌ی خبرها اصلاً دیده نمی‌شوند.
- **انتشار:** در تب «خبرها» تنظیمات FTP را پر کنید (میزبان `ftp.mp-apdl.ir`، مسیر
  `/public_html/goshyar`) ← «تست اتصال» ← «ذخیره». بعد خبر را بنویسید ← «امضا و انتشار»: در یک اتصال
  اول عکس‌ها (`notices/<sha>.webp`) و آخر `notices.json` بالا می‌روند. بی میزبان FTP، مثل قبل به R2
  (`npx wrangler@4 login`) می‌رود. برنامه‌ی باز هر دو دقیقه و برنامه‌ی بسته حدود هر ربع ساعت نگاه
  می‌کند؛ یک خبر در هر نوبت.
- **حریم خصوصی:** چیزی از گوشی فرستاده نمی‌شود؛ پیوند خبر فقط بعد از دروازه‌ی والدین باز می‌شود و
  والدین می‌توانند خبرها را در «بخش والدین ← اعلان‌ها» خاموش کنند.

## اعلان‌ها (پوشه)
- **دریافت در برنامه:** فقط وقتی `pushe.token` در `services.properties` باشد، SDK پوشه در برنامه گذاشته می‌شود.
  والدین در «بخش والدین ← اعلان‌ها» اجازه‌ی اعلان را می‌دهند (اندروید ۱۳ به بعد).
- **ارسال:** استودیو (`tools/voice-studio`) ← تب **ارسال اعلان**: عنوان، متن، عکس (نشانی https) و پیوند.
  توکن **وب‌سرویس** پوشه را همان‌جا ذخیره کنید؛ با توکن SDK فرق دارد.

## اگر بازار گفت «برنامه بلافاصله بسته می‌شود»

این پیغام یعنی **پروسه مرده**، نه اینکه صفحه‌ای خطا داده: خطای Dart صفحه‌ی قرمز یا صفحه‌ی خالی
می‌دهد، ولی «Keeps Stopping» فقط از لایه‌ی اندروید می‌آید — کلاس Application، یک ContentProvider
که پیش از اولین Activity اجرا می‌شود، یا کدی در `MainActivity` که پاسخ‌ندیده خطا بدهد.

### متن دقیق خطا را بگیرید
با کابل به گوشی وصل شوید (حالت توسعه‌دهنده و «اشکال‌زدایی USB» روشن) و پیش از باز کردن برنامه:

```powershell
adb logcat -c
```

```powershell
adb logcat AndroidRuntime:E goshyar:V *:S
```

حالا برنامه را روی گوشی باز کنید. چند خطی که با `FATAL EXCEPTION` شروع می‌شود همان علت است؛
همان را کامل نگه دارید. برای گرفتن فقط آخرین کرش ثبت‌شده:

```powershell
adb logcat -b crash -d
```

### آزمایش روی اندروید ۱۲ پیش از انتشار
کرشی که فقط روی یک نسخه‌ی اندروید می‌آید با گوشی خودتان پیدا نمی‌شود. در Android Studio
(**Tools ← Device Manager ← Create Device**) یک شبیه‌ساز با **API 31 (Android 12)** بسازید و
نسخه‌ی release را روی همان نصب کنید:

```powershell
flutter build apk --release
```

```powershell
adb install -r build\app\outputs\flutter-apk\app-release.apk
```

### چه چیزی در این نسخه عوض شد
- **WorkManager دیگر خودش بالا نمی‌آید.** راه‌اندازی خودکارش یک ContentProvider است که پیش از هر
  خط کد ما اجرا می‌شود؛ خطا در آن لحظه جایی برای گرفتن ندارد و پروسه را می‌کشد. آن راه‌انداز از
  Manifest برداشته شد و `GoshyarApplication.kt` پیکربندی را می‌دهد تا WorkManager در لحظه‌ی نیاز و
  داخل `try/catch` ساخته شود (`NoticeWork.kt`).
- **`MainActivity` دیگر خطا بیرون نمی‌دهد:** بستن کانال‌ها، `onPause`، `onNewIntent`، `onDestroy` و
  پاسخ اجازه‌ی اعلان همه در `runCatching` هستند. بدترین حالت: کانالی که بالا نیامده و بازی بی‌خبر
  و بی‌خرید کار می‌کند.
- **R8 صریحاً خاموش است** (`isMinifyEnabled = false`). کوچک‌سازی روی کدی که با بازتاب کار می‌کند
  (Poolakey، WorkManager) نسخه‌ی release را در همان لحظه‌ی باز شدن می‌شکند در حالی که debug سالم
  است. اگر روزی روشنش کردید، قاعده‌های `android/app/proguard-rules.pro` آماده‌اند و خروجی را باید
  روی گوشی واقعی آزمایش کنید.
- **راه‌اندازی Dart هیچ گامی ندارد که برنامه را ببندد** (`lib/main.dart`): هر گام جداگانه گرفته
  می‌شود، پخش صدا اگر بالا نیاید بازی بی‌صدا ادامه می‌دهد، و کافه‌بازار و خبرها بعد از اولین فریم
  صدا زده می‌شوند نه پیش از آن. اگر محتوای بازی اصلاً خوانده نشود، صفحه‌ی فارسی
  `StartupErrorApp` نشان داده می‌شود.
- **حداقل اندروید ۱۰** (`minSdk = 29`) به‌جای عدد متغیر Flutter.

## چه چیزی آزموده شده و چه چیزی نه (صادقانه)
- کد Dart، قفل مرحله‌ها و برگه‌ی خرید با ۳۳ آزمون خودکار آزموده شده‌اند.
- **کد Kotlin پرداخت و اعلان، و ساخت Gradle، در محیط توسعه ساخته نشده‌اند** (دسترسی به سرورهای گوگل و
  JitPack بسته بود). اولین ساخت روی سیستم شماست؛ اگر خطا داد، متن کامل را بفرستید.
- همین مورد برای تغییرهای رفع کرش هم صادق است: `GoshyarApplication.kt`، تغییر Manifest و `minSdk = 29` فقط
  خوانده شده‌اند، نه ساخته. سمت Dart با ۵۲ آزمون و `flutter analyze` آزموده شده است.
- ارسال اعلان استودیو با یک سرور ساختگی آزموده شده، نه با سرور واقعی پوشه. اولین ارسال را با یک گوشی
  آزمایشی امتحان کنید؛ پاسخ کامل سرور در استودیو نشان داده می‌شود.
